# Offensive Security

A public learning spot for offensive security concepts, penetration testing methodology, pentest types, and tool mapping.

## Current Features

- Public-facing offensive security learning page.
- Scope explainer for Red Team, Penetration Testing, Vulnerability Assessment, and Vulnerability Management.
- Interactive scope section with numbered navigation and a focused explanation card.
- Penetration testing methodology flow.
- Pentest type selector for Web App, Network, and API testing.
- Tool recommendations mapped by methodology step and pentest type.
- Tool cards with direct links.
- Classy Apple/NordPixel-inspired visual direction.
- Full-bleed dark hero section with floating navigation.
- Animated terminal-style command typing in the hero background.
- Responsive layout for desktop and mobile.
