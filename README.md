# Offensive Security

A public learning spot for offensive security concepts, penetration testing methodology, pentest types, and tool mapping.

## Project Structure

```text
dist/
  index.html
  styles.css
  app.js
package.json
vercel.json
```

## Run Locally

```bash
npm install
npm start
```

The site will serve the `dist` folder.

## Deploy To Vercel

1. Push this project to GitHub.
2. Import the GitHub repository into Vercel.
3. Vercel should detect:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Notes

This is a static website. There is no backend, database, or authentication yet.
